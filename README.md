# Direct Commander MCP для Codex

Плагин читает названия и статусы кампаний из открытого Яндекс Директ Коммандера для Windows. Он прокручивает таблицу до нужного столбца, возвращает ее в исходное положение и сверяет обе координаты. Если во время чтения вы прокрутите таблицу сами, операция остановится и сохранит вашу новую позицию.

## Установка в Codex

Потребуются Windows, Codex с командой `plugin marketplace add`, Node.js 22 или новее с npm и PowerShell 7.5 или новее. Установите Директ Коммандер в стандартный каталог текущего пользователя и откройте его в том же сеансе Windows, где работает Codex.

```powershell
codex plugin marketplace add rdsolod-ui/direct-commander-mcp --ref v1.1.0
codex plugin add direct-commander@direct-commander-marketplace
```

Откройте новый чат Codex и попросите: **«Покажи названия и статусы видимых кампаний в правой панели Коммандера»**. При первом запуске npm загружает зависимости. Доступ к API Директа и OAuth-токен для чтения окна не нужны. Если сервер `direct-commander` уже подключен вручную, используйте существующее подключение или выберите плагин при переносе на другой ПК.

## Инструменты

| Инструмент | Действие |
| --- | --- |
| `commander_status` | Определяет версию приложения и перечисляет открытые окна. |
| `commander_list_panels` | Показывает вкладки, выбранную вкладку и фильтр каждой панели. |
| `commander_read_grid` | Читает строки и столбцы в видимой области таблицы. |
| `commander_read_columns` | Находит столбцы по точным заголовкам, совмещает значения по строкам и восстанавливает прокрутку. |
| `commander_select_tab` | Переключает вкладку выбранной панели. |
| `commander_set_quick_filter` | Изменяет быстрый фильтр после сверки прежнего значения. |

Сначала получите идентификатор окна через `commander_status`, затем выберите панель и текущую вкладку из `commander_list_panels`. Для кампаний передайте в `commander_read_columns` заголовки `["Название", "Статус"]`. Результат относится к видимым строкам с учетом фильтра. Значения соответствуют состоянию в локальном приложении. У ячеек, представленных только значком, доступный текст может отсутствовать.

Данные прочитанных ячеек возвращаются вызывающему клиенту Codex. Сервер взаимодействует с окном через Windows UI Automation. Быстрый фильтр и переключение вкладки меняют только представление таблицы.

## Проверка из исходников

```powershell
npm ci --ignore-scripts
pwsh -NoProfile -File ./check-scroll.ps1
node ./server.cjs
```

Последняя команда запускает MCP-сервер по stdio и ожидает JSON-RPC от клиента. Чтобы пересобрать пакет плагина из корня репозитория, выполните `npm pack --pack-destination ./plugins/direct-commander`. Версия архива в манифесте MCP должна совпадать с версией пакета.

Независимый проект для работы с приложением Яндекс Директ Коммандер.
